# Ears & Keys website

Static website starter for GitHub Pages.

## Files

- `index.html` — all homepage content
- `styles.css` — design and responsive layout
- `script.js` — mobile menu + current year

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `ears-and-keys`.
2. Upload these three files to the top level of the repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save.
7. GitHub will provide the public Pages URL.

## Before publishing

Search `index.html` for:
- `YOUR-EMAIL-HERE`
- `Your photo here`
- the three testimonial placeholders
- `Explore LISTEN soon`

Replace those with your real information.
